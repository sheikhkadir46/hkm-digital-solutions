# HkM Biz — Premium Digital Agency Website

A modern high-end digital agency landing page built using pure HTML, CSS, and JavaScript.

Designed with a luxury dark theme, smooth animations, responsive layouts, and premium UI aesthetics inspired by modern creative agencies.
